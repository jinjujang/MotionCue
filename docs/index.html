Abstract

Motion control in image-to-video (I2V) generation should make an object follow a given motion without losing what the backbone already does well, a scene that moves naturally and responds to the prompt. However, existing methods that use a reference video made by moving only the object in the input image encode the entire reference into the initial noisy latent, and thus also convey its frozen scene, limiting scene dynamics and prompt responsiveness. We propose MotionCue, a training-free and mask-free method that decouples the intended motion from the frozen scene. In the latent space, MotionCue extracts the motion residual by subtracting a video that repeats the first reference frame, and injects it once as a cue right after the first denoising step. Since the content has only begun to form at this point, even a small residual acts as a strong cue that guides the trajectory early in sampling, while the rest of the generation is left to the model. To evaluate whether the scene remains responsive under motion control, we construct RISER, a benchmark of scenes whose surroundings react to the moving object, paired with prompts of varying dynamics. On RISER, which reveals how much motion control reduces what the backbone generates, MotionCue follows the reference trajectory while keeping scene dynamics, prompt responsiveness, and video quality close to those of the backbone without motion control.

1. Why a Residual?

In a cut-and-drag reference, only the object moves and the rest of the frame stays frozen as in the input image. Encoding the whole reference therefore carries this frozen scene into the generated video as well. Subtracting a static video that repeats the first frame from the reference cancels the frozen part and leaves only the motion of the object as a residual.

2. One Cue, Then Hands Off

MotionCue computes this residual in the latent space and adds it to the model only once, right after the first denoising step. The backbone generates everything else as usual.

3. Trajectory Control without Freezing the Scene

MotionCue moves the object along the path of the reference while the surroundings react to it. Every method uses the same image, reference, prompt, and seed on Wan2.2-I2V-A14B.
